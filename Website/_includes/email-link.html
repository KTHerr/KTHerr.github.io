{%- comment -%} Spam-resistant email link. The address never appears in the served HTML as a single string: the local part and the domain are emitted separately and each reversed, so nothing in the markup matches the user@host pattern harvesters scan for. The link is assembled in the browser by the small script in _layouts/default.html. Params: include.class extra classes for the include.label visible text (omit for an icon-only link) include.icon any truthy value to prefix the envelope glyph include.show any truthy value to render the address as the link text {%- endcomment -%} {%- assign eu = site.email_user | split: "" | reverse | join: "" -%} {%- assign ed = site.email_domain | split: "" | reverse | join: "" -%} {% if include.icon %}{{ icon_mail }}{% endif %}{% if include.label %}{{ include.label }}{% endif %}
